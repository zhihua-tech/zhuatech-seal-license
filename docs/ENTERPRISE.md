# 企业印章证照与资质管理系统企业能力

## 领域覆盖

- **印章台账**：维护实体印章、电子印章、保管人、状态和适用范围
- **用印申请**：登记文件、份数、事由、金额、相对方和使用方式
- **分级审批**：按印章、金额、合同类型和风险执行多级审批
- **用印执行**：核验授权、记录盖印、影像、经办人、时间和设备
- **证照管理**：管理营业执照、许可证、登记证和原件保管
- **企业资质**：维护资质等级、适用业务、发证机关和有效期
- **借用归还**：登记借用人、用途、期限、签收、归还和逾期
- **年审与续期**：形成到期计划、材料清单、办理进度和新证归档
- **风险与审计**：识别越权、异常地点、逾期未还和未授权使用

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业印章证照与资质管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `OA_ESIGN`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
